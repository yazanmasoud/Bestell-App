# Bestell App

Bestell App is a JavaScript-based food ordering web application inspired by Lieferando.
The focus of this project is on dynamic rendering, state management, and user interaction using vanilla JavaScript.

## Description
The application displays a restaurant page with a dynamically generated menu.
Dishes are rendered from JavaScript objects and grouped into categories.
Users can add items to a shopping cart, adjust quantities, and place a simulated order.

All cart logic, price calculations, and UI updates are handled on the client side without any external libraries or frameworks.

## JavaScript Functionality
- Dynamic rendering of menu items and categories from JavaScript data
- State-based shopping cart management
- Add, remove, increase, and decrease cart items
- Automatic recalculation of totals on every cart update
- DOM manipulation for real-time UI updates
- Separation of rendering logic and data logic

## Responsive Behavior
The shopping cart adapts to different screen sizes.
On smaller devices, the cart is displayed as a dialog and can be opened via a button.
All cart interactions remain fully functional across breakpoints.

## Tech Stack
- HTML
- CSS
- Vanilla JavaScript

## Project Scope
This project is a frontend-only application.
Orders are simulated for demonstration purposes and do not trigger any backend or payment processes.
